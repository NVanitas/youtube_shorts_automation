# Privacy Policy for Nicosaurus YouTube Automation

Last updated: August 25, 2026

## 1. Overview
Nicosaurus YouTube Automation is a personal automation tool created to manage and upload content to the Nicosaurus YouTube channel.

## 2. Information Collected
This application only accesses data authorized by the channel owner through Google OAuth 2.0 to upload videos and publish comments on the authorized YouTube channel. No personal data from third-party viewers or external users is collected, stored, shared, or sold.

## 3. Use of Data
All access tokens are stored securely and used solely for authenticating API requests to the YouTube Data API v3 on behalf of the channel owner.

## 4. Third-Party Services
This application interacts with:
- Google YouTube Data API v3 (subject to Google Privacy Policy: https://policies.google.com/privacy)

## 5. Contact
For any questions regarding this application, please contact the repository owner at https://github.com/NVanitas/youtube_shorts_automation
